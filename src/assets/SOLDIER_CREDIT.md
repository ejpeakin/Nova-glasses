# Soldier character

`soldier.js` embeds the **"Vanguard" soldier by Mixamo** (https://www.mixamo.com), the
`Soldier.glb` model that ships with the three.js examples
(`examples/models/gltf/Soldier.glb`, credited there as "model from mixamo.com").

Mixamo characters are royalty-free to use in personal and commercial games. They may
not be resold or redistributed as standalone character files; here the model is part
of the game. The game drives the model's skeleton from its own procedural animation,
so the clips that come with the file are not used.
